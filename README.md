# 🔍 Advance-RAG

## 📌 Overview

This repository explores **Retrieval-Augmented Generation (RAG)** in depth, covering both foundational concepts and advanced agentic architectures.  
The project is organized as a **progressive series of Jupyter notebooks**, each focusing on a specific RAG component, from query transformation to adaptive agents and knowledge graph integration.
The goal is to provide **hands-on, practical implementations** of modern RAG systems using real-world patterns and research-backed techniques.

---
